# 🚀 KYVO - Enterprise E-Commerce & Business Management System (BMS)

KYVO is a full-stack, enterprise-grade Business Management System and E-Commerce platform built using **ASP.NET Core 8.0 MVC** and **Entity Framework Core**. It provides business owners with real-time sales analytics, complete inventory control, order handling, and client record management.

## 🛠️ Tech Stack & Architecture

- **Backend Framework:** ASP.NET Core 8.0 MVC
- **Database & ORM:** Entity Framework Core / SQL Server
- **Frontend UI:** Bootstrap 5, Custom CSS3, HTML5
- **Analytics & Visuals:** Chart.js
- **Architecture:** Repository & MVC Pattern

---

## ⚡ Key Features

- 📈 **Real-Time Data Visualizations:** Dynamic bar/doughnut charts for sales & status ratios.
- 🛒 **Storefront & Ordering:** Seamless order creation from customer-facing shop.
- 📦 **Inventory Operations:** Stock tracking, active status toggles, and pricing controls.
- 📄 **Invoice Generation:** Quick invoice printing for fulfilled customer orders.
- 🔒 **Clean Architecture:** Modular controllers, strongly-typed views, and database isolation.
